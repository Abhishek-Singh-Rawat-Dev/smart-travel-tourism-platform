# 🌍 Smart Travel & Tourism Platform (Major Project)

A full-stack web application designed for smart tourism, automated AI trip planning, booking management, real-time emergency safety, and group expense management.

---

## 📁 Project Architecture

The project has been organized into systematic layers:

- **[`frontend/`](file:///Users/abhisheksinghrawat/Desktop/major%20project/frontend)**: Client-side UI (HTML pages, CSS stylesheets, client JavaScript).
- **[`backend/`](file:///Users/abhisheksinghrawat/Desktop/major%20project/backend)**: Server logic (Express app, REST API routes, middlewares).
- **[`database/`](file:///Users/abhisheksinghrawat/Desktop/major%20project/database)**: MongoDB Mongoose models, database config, and seeders.
- **[`docs/`](file:///Users/abhisheksinghrawat/Desktop/major%20project/docs)**: Word reports, PDF presentations, and DFD Diagrams.
